# Student Management System

A simple student management web app built with HTML, CSS and JavaScript.

## Live Demo

https://joni4986.github.io/student-management-system/

## Features

- Add students
- Edit students
- Delete students
- Search students
- Pass / Fail status
- Stats dashboard
- Clear all students
- Saves data using localStorage

## Tech Stack

- HTML
- CSS
- JavaScript
- localStorage

## What I Learned

Through this project, I practiced working with forms, DOM manipulation, arrays, events, localStorage, and basic CRUD logic.
